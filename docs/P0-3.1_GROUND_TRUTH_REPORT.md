## 2. Function Boundary Accuracy — 真实数据

### 初始状态（修复前）

| 指标 | 值 |
|------|-----|
| Total Expected gt_* functions | 26 |
| TP | 3 |
| FP | ~2 |
| FN | 23 |
| **Recall** | **11.5%** |
| Precision | ~60% |

**根因**：FOX 的 x64 prologue 检测只匹配固定字节模式（`sub rsp,0x20`、`mov [rsp+8],rcx`、`push rbp;mov rbp,rsp`），不覆盖：
- MSVC `sub rsp,0x18`（不同栈大小）
- MSVC leaf 函数 `mov [rsp+0x10],edx`（参数影子空间存储，无栈分配）
- -O2 优化后的函数序言

### 修复内容

1. **通用 `sub rsp, imm8` 检测**（`48 83 EC NN`，任意立即数）
2. **通用 `sub rsp, imm32` 检测**（`48 81 EC NN NN NN NN`）
3. **`mov [rsp+disp8], r32` 检测**（`89 [40-7F] 24 NN`，MSVC 参数影子空间）
4. **`mov [rsp+disp8], r64` 检测**（`48/4C 89 [40-7F] 24 NN`）
5. **前置填充约束**：所有新模式要求前一字节为 `0xCC`(int3) 或 `0x90`(nop) 或 section 起始，避免匹配函数体内的同类指令

### 修复后状态

| 指标 | -O0 | -O2 | 合计 |
|------|-----|-----|------|
| Expected gt_* functions | 13 | 13 | 26 |
| TP | 11 | 3 | 14 |
| FN | 2 | 10 | 12 |
| **Recall** | **84.6%** | **23.1%** | **53.85%** |
| Precision (gt_* region) | ~45% | ~25% | **31.1%** |

### 已知缺口

1. **-O2 Recall = 23.1%**：优化后函数可能无 `sub rsp`（leaf function）、无 int3 填充、或被内联/合并
2. **Precision = 31.1%**：`sub rsp` 和 `mov [rsp]` 模式仍有一定 FP，需后续引入 CFG 递归下降验证
3. **Boundary End Error**：多个函数的 estimated_end 与 Ground Truth 不符（线性扫描写法限制）
4. **03_nested_branch / 08_switch** 各有 1 FN：可能是函数入口前无 int3 填充

## 8. Known Limitations

1. **-O2 Function Discovery Recall = 23.1%**：优化后函数序言检测不足，需引入基于 CFG 递归下降的函数发现
2. **Precision = 31.1%**：prologue 模式匹配仍产生 FP，需用 CALL 引用 + CFG 可达性过滤
3. **Function Boundary End 不准确**：线性扫描写法导致 estimated_end 偏差，需 CFG 驱动的函数边界
4. **Ground Truth 仅覆盖 gt_* 函数**：CRT/runtime 函数未纳入 Ground Truth（数量大且编译器相关）
5. **CFG/SSA 的 Ground Truth 级 differential 未实现**：当前只有 function boundary 级别的真实比较
6. **GitHub Actions 未实跑**：需用户批准推送
7. **Evidence JSON 序列化问题**：WithEvidence 的 confidence/evidence 在 --json 输出中为空
