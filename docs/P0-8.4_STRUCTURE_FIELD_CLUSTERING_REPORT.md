## 2. 实现方法

### 2.1 字段收集

在 `try_field_access` 和 `try_parse_memory_operand` 输出 `global_X->field_OFFSET` 时，记录 `(global_X, offset)` 到 `field_accesses`。

### 2.2 聚类算法

1. 按对象分组所有访问过的 offset
2. 排序并去重
3. 检测连续字段（步长 4 字节 = DWORD）：
   - `+0xDBC844 +0xDBC848 +0xDBC84C` → cluster: 12 bytes, 3 fields

### 2.3 输出格式

在每个函数末尾输出注释块：
```c
/* P0-8.4 Structure Candidates:
 * Object: global_46E920
 *   Fields (3 unique):
 *      +0xDBC844 +0xDBC848 +0xDBC84C
 *   Clusters (1): +0xDBC844..+0xDBC84C (12 bytes, 3 fields)
 */
```

### 2.4 安全限制

- 只收集 global 对象字段访问，不分析栈/寄存器
- 步长固定 4 字节（DWORD）
- 至少 2 个连续字段才形成 cluster
- 不猜字段名、不猜类型、不猜结构体名
