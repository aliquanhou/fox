## 2. 实现方法

### 2.1 FieldEvidence 数据结构

```rust
field_accesses: HashMap<String, HashMap<u64, usize>>
// object_name -> (offset -> access_count)
```

### 2.2 升级输出格式

**P0-8.4（旧）**:
```c
/* P0-8.4 Structure Candidates:
 * Object: global_46E920
 *   Fields (3 unique): +0xDBC844 +0xDBC848 +0xDBC84C
 *   Clusters (1): +0xDBC844..+0xDBC84C (12 bytes, 3 fields)
 */
```

**P0-8.5（新）**:
```c
/* P0-8.5 Structure Evidence:
 * Object: global_46E920
 *   Fields: 3 unique, 3 total accesses
 *   +0xDBC844   size:4  accesses:1
 *   +0xDBC848   size:4  accesses:1
 *   +0xDBC84C   size:4  accesses:1
 *   Clusters (1): +0xDBC844..+0xDBC84C (12 bytes, 3 fields)
 *   Confidence: MEDIUM
 */
```

### 2.3 数组模式检测

连续 offset 步长 4 且 cluster 长度 >= 8 → 标记为 `POSSIBLE_ARRAY`：
```c
Clusters (1): +0x100..+0x11C (POSSIBLE_ARRAY, 8 elements)
```

### 2.4 置信度

- **MEDIUM**: >= 3 个字段且有 struct cluster
- **LOW**: 1-2 个字段
- **NONE**: 无字段

## 4. 已知限制（GAP）

### GAP-P0-8.5-READ-WRITE-DISTINCTION
当前 emitter 层只记录总访问次数，无法区分读和写。要区分 read/write 需要回到 SSA instruction 级别。

### GAP-P0-8.5-CROSS-FUNCTION
当前统计在单函数内进行。跨函数字段聚类需要全局汇总。

### GAP-P0-8.5-SIZE-DETECTION
当前固定假设 4 字节步长。未根据指令大小区分 WORD/DWORD/QWORD。
