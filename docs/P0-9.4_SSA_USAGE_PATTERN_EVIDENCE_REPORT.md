## 4. 已知限制（GAP）

### GAP-P0-9.4-SSA-OPERATION-MINING（P1）
当前 emitter 层无法真正跟踪 SSA 操作模式（compare, arithmetic, dereference, indirect call）。这些需要 Statement 级别的表达式分析。

当前实现基于访问频率和 cluster 位置，这是保守的近似。

真正的 SSA 行为分析需要：
- 解析 If 条件表达式，检查是否涉及某个 global->field
- 解析 CallStmt 参数，检查是否涉及某个 global->field
- 解析 Assign rhs，检查是否解引用了某个 global->field

这些超出了当前 emitter 层的能力范围，需要在分析层实现。
