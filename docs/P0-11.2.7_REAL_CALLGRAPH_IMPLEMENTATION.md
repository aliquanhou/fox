## 2. 真实数据结构（验收项）

### CallEdge（`callgraph.rs`）
```rust
pub struct DecompilerCallEdge {
    pub caller: u64,            // 调用者函数地址
    pub callee: CallTarget,     // Address / Symbol / Unknown
    pub callsite: u64,          // 来自 StatementEvidence.instruction_addresses
    pub kind: DecompilerCallKind, // Direct / Symbol / Unknown
}
```

### CallGraph
```rust
pub struct DecompilerCallGraph {
    pub edges: Vec<DecompilerCallEdge>,
    outgoing: HashMap<u64, Vec<usize>>,  // caller -> edges
    incoming: HashMap<u64, Vec<usize>>,  // callee_addr -> edges
}
```

### Builder 与 Pipeline
```
SSA CallStmt
  -> DecompilerCallGraphBuilder::build(&[&DecompilerFunction])
  -> 递归遍历 If/GuardClause 嵌套 body
  -> DecompilerCallEdge
  -> DecompilerCallGraph
```

### Query API
- `edge_count() -> usize`
- `caller_count() -> usize`
- `callees_of(caller) -> Vec<&CallEdge>`
- `callers_of(callee_addr) -> Vec<u64>`（仅 Address 目标入索引）
- `kind_counts() -> (direct, symbol, unknown)`

## 6. Fail-Closed 原则

- 无 outgoing 边的函数**不输出**证据块（leaf 保持沉默，不编造）
- `CallTarget::Unknown` 原样保留为 `call_unknown`，**绝不猜目标**
- `CallTarget::Symbol` 不进 incoming 索引（无规范地址）
- emitter 只通过 `set_callgraph()` **读取**图，不自己计算边

---

## 7. 已知 GAP

1. **Symbol/Unknown 不进 caller 反查**：只有 Address 内部函数能 `callers_of`。
2. **callsite 地址**：取 `instruction_addresses.first()`，若 evidence 缺失则为 0。
3. **跨 PE 边界**：symbol 边只记录名字，未关联到 fox-analysis 的 IAT 解析。
4. **函数指针/vtable 间接调用**：当前归为 Unknown，待 P0-7.x 动态解析后回填。
