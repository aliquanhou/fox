## 2. 实现方法

### 2.1 Role Inference Rules（保守，Evidence-driven）

| 条件 | 候选角色 | 置信度 | Evidence |
|------|----------|--------|----------|
| >20 accesses AND >=5 fields | update-like | MEDIUM | global writes, fields touched |
| >5 accesses AND >=2 fields | accessor-like | LOW | global reads, fields touched |
| >10 accesses | state-update-like | LOW | high frequency accesses |
| 其他 | UNKNOWN | NONE | insufficient evidence |

### 2.2 Evidence Trace

每个角色输出必须包含 Evidence Trace：
```
*   Candidate Role: update-like (MEDIUM confidence)
*   Evidence: global writes: 24, fields touched: 8
```
