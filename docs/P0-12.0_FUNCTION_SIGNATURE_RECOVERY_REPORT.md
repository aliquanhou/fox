## 2. 真实数据结构

```rust
pub enum ParameterLocation { Stack, Register, Unknown }
pub struct FunctionParameter { index, location, source, call_sites }
pub enum ReturnEvidence { Condition, Value, Unknown }
pub enum SignatureConfidence { High, Medium, Low }
pub struct FunctionSignature { function, parameters, return_evidence, confidence }
pub struct SignatureMap { signatures: HashMap<u64, FunctionSignature> }
```

### Builder Pipeline
```
CrossFunctionDataFlowGraph (P0-11.3)
  + CallGraph (P0-11.2.7)
  ▼
FunctionSignatureBuilder::build(funcs, dataflow, callgraph)
  ├─ 按 callee 聚合 ArgumentFlow → 参数 #i + 来源众数
  ├─ 按 callee 聚合 ReturnFlow  → ReturnEvidence
  └─ Unknown/symbol callee 跳过（不编造型节点）
  ▼
SignatureMap
```

### Query API
- `get(function) -> Option<&FunctionSignature>`
- `len()` / `is_empty()`
- `with_param_count(n) -> usize`

## 6. Fail-Closed / 禁止事项遵守

- 无 caller 的函数不输出签名（leaf 沉默）
- Unknown/symbol callee 不编造签名节点
- 无参数证据时输出 `(none recovered)`，不猜 `int arg0`
- 不命名函数、不判业务语义、不生成确定类型
- emitter 只 `set_signatures()` 后读取，不自己分析

---

## 7. 已知 GAP

1. **Calling convention 未自动识别**：当前参数 location 只做粗略 Register/Stack，未区分 cdecl/stdcall/fastcall/thiscall（需 stack cleanup 证据）。
2. **callee 内部栈参数槽未建模**：参数聚合来自 caller PUSH，未验证 callee 实际读取了哪个 slot。
3. **ReturnEvidence 只到 consumer 类别**，未恢复返回值具体类型（待 P0-13 Type Propagation）。
4. **参数名未恢复**：当前只有 `arg0/arg1` 槽位，无业务名（不猜）。
5. mem=0 来源（P0-11.3 GAP）继续影响 MemoryLoad 参数计数。
