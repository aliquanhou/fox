## 8. 审计结论

**当前 FOX 能力定位**：

```
Layer 1: Identity (调用了谁？) ✅
Layer 2: Behavior (调用前后发生了什么？) 🟡 部分
Layer 3: Semantics (这个调用承担什么功能？) ❌
```

**从当前层进入下一层，最小缺口**：

1. **函数输入分析**：统计每个函数读取的全局字段和参数
2. **函数输出分析**：统计每个函数写入的全局字段和返回值
3. **调用模式分类**：基于调用上下文推断函数角色

---

## 9. 推荐下一步

**P0-10.1 Function I/O Analysis**（分析层）：
- 统计每个函数的读/写全局字段
- 统计每个函数的返回值来源
- 统计每个函数的调用模式
- 输出函数行为摘要

这是从"反汇编事实"进入"函数语义理解"的关键一步。
