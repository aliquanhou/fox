## 2. 真实数据模型

```rust
pub struct Variable {
    index: usize,              // variable_0..N
    register: String,          // eax
    def_versions: Vec<u32>,    // 该寄存器所有 SSA 版本
    has_phi: bool,
    has_memory_store: bool,
}
pub struct VariableMap { per_function: BTreeMap<u64, Vec<Variable>> }
```

### Pipeline
```
DecompilerFunction.statements (Assign / PhiAssign / CallStmt / Return / If/Guard body)
  ▼ 递归 walk
  ├─ Assign{lhs: Variable(name,ver)} -> 记录 def
  ├─ PhiAssign{lhs}                   -> 记录 def + has_phi
  ├─ Memory target                    -> has_memory_store
  └─ Expression 树里的 Variable{name,ver} -> uses 也收录
  ▼ 按 (function, register name) 分组
VariableMap
```

### Query（Phase 7）
- `variables_of_function(addr)`
- `variable_of_register(addr, reg)`
- `len()` / `function_count()`

## 7. 已知 GAP

1. **变量未关联类型**：本阶段 Variable 不带 type_candidate；TypeMap（P0-13）key 是参数槽/返回值/字段，不覆盖函数内局部 SSA value。局部变量类型集成待后续。
2. **uses/defs 未细分**：当前只列 def_versions，未做精确 use-def 反查（uses_of_variable/definition_of_variable 仅有 def 侧）。
3. **栈变量未命名**：Memory target 只标 has_memory_store，未区分 local_0/local_1（需栈槽分析）。
4. **FLAGS/eip 等也成 variable**：证据显示 FLAGS/eip 被收录——它们是 SSA 寄存器，语义上非用户变量，后续可过滤。
5. 跨函数变量（同一全局/栈位置在多函数共享）未建模。
