# v1.17.1-R1 Architecture Audit

## 1. SSA Variable Identity Location
- `c_ast.rs:88 tmp_name()` — SSA value identity = `(reg: String, version: u32)`
- Key = `(reg, version)` 是变量身份

## 2. SSA Variable → local_N
- `c_ast.rs:94` — `format!("local_{}", next_tmp)`
- 每个唯一 (reg, version) 映射到一个 local_N

## 3. Declaration Location
- `c_ast.rs:364` — `uint32_t local_0, local_1;`

## 4. Expression Reference Location
- `c_ast.rs:124,173,206,213,242,286` — 所有 `CExpr::Var(self.tmp_name(...))`

## 5. AstScope
- 当前没有独立 AstScope
- var_map 就是 symbol 表

## 6. var_map Structure
```rust
var_map: HashMap<(String, u32), String>
// key = (reg, version) = SSA identity
// value = local_N = C symbol name
```

## 7. Semantic Name Extension Point
- 在 var_map 之外加 `semantic_names: HashMap<(String, u32), String>`
- 或者在 tmp_name() 里优先查 semantic_names

## R0 Limitation
- `body_buf.replace("local_0", "file_handle")` 是 Renderer 全文字符串替换
- 风险：local_01 → file_handle1（substring bug）
- R1 必须在 var_map 层解决
