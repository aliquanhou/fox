## 2. 实现方法

### 2.1 架构发现确认

```
SSA Analysis
      ↓
Behavior Evidence (Analysis Layer)
      ↓
Emitter Display
```

而不是：

```
SSA Analysis
      ↓
Emitter
      ↓
猜类型
```

## 4. 已知限制（GAP）

### GAP-P0-9.5-ANALYSIS-LAYER-MINING（P1）
真正的 SSA 行为分析需要在分析层实现：
- 扫描 If 条件表达式，检查是否涉及某个 global->field
- 扫描 CallStmt 参数，检查是否涉及某个 global->field
- 扫描 Assign rhs，检查是否解引用了某个 global->field

这些需要深入 SSA 数据流分析，当前 emitter 层无法完成。
