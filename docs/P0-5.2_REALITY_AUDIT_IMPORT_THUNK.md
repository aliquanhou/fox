### 2.2 Function Discovery — Import Thunk 被误识别为函数 ❌

1. **Phase 3** (line 207-227): 扫描所有 CALL target，将被引用的地址加入函数列表

2. **Phase 4.3** (line 571-680, `follow_thunks`): 只处理**直接**无条件 JMP（`first.jump_target.is_some()`）
   - Import thunk 是 `jmp [IAT]`（**间接** JMP），`jump_target = None` → **不被处理**
3. **结果**: Import thunk 保留在函数列表中，作为普通函数（High confidence 0.76）

## 4. Architecture Proposal (最小改动)

### 4.1 Import Thunk Recognition (新函数)

在 `FunctionDiscovery` 中新增 `identify_import_thunks()`:
- 输入: binary, discovered functions, iat_map
- 对每个函数，反汇编第一条指令
- 如果是 `jmp [absolute_address]`（间接 JMP，操作数可解析为绝对地址）
- 检查 absolute_address 是否在 iat_map 中
- 如果是 → 标记为 ImportThunk，记录 resolved symbol
- **Fail-closed**: 只有 `jmp [mem]` + IAT membership 证明 → ImportThunk

### 4.2 Identity Model 扩展

在 `IdentityKind` 中新增 `ImportThunk` 变体:
```rust
pub enum IdentityKind {
    Canonical,
    Thunk,           // direct JMP thunk (MSVC O2 jump islands)
    ImportThunk,     // NEW: jmp [IAT] → external function
    Folded,
    Alias,
    Unknown,
}
```

`build_identity_table` 中增加 ImportThunk 分类逻辑。

### 4.3 Function Discovery 调整

- ImportThunk 保留在 Binary Entity 列表中（Identity = ImportThunk）
- 但不参与普通 Native Function 统计/分析（不跑 SSA/DataFlow）
- 在 `analyze_binary_native` 中过滤 ImportThunk，或添加标记

### 4.4 Call Graph 修复

- 构建 `thunk_map: HashMap<u64, (dll_name, func_name)>`（import thunk 地址 → external symbol）
- `classify_call` 中，direct call target 先查 thunk_map
- 如果命中 → `CallEdgeKind::External` + `resolved_symbol`
- DirectInternal 不再包含 import thunk calls

### 4.5 Evidence

ImportThunk identity evidence chain:
```
Instruction (jmp [IAT])
  → IAT address (e.g., 0x456154)
  → Import entry (KERNEL32.dll!SomeFunction)
  → Identity = ImportThunk
```

External call edge evidence:
```
CALL instruction @ 0x...
  → target = 0x455E40 (ImportThunk)
  → IAT = 0x456154
  → KERNEL32.dll!SomeFunction
  → DirectExternal
```

## 5. 不做的事情

- ❌ 不修改 x86 Function Discovery scoring（不提高 Confirmed 数量）
- ❌ 不把所有 `jmp [mem]` 都认成 ImportThunk（必须 IAT membership 证明）
- ❌ 不修改已 SEALED 的 Register SSA / Memory SSA / DataFlow 语义
- ❌ 不做完整 Type Recovery / Decompiler
- ❌ 不做 ELF/Mach-O/ARM64
