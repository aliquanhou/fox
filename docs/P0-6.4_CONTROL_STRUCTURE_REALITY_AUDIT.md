### 1.2 DominatorTree — IMPLEMENTED

### 1.3 Post-Dominator — NOT IMPLEMENTED

全仓库搜索 `post_dom|PostDom|postdom` 返回 0 结果。

**影响评估：** 经典 if/else 结构化恢复需要 post-dominator 来确定 join block。但对于 **early-return / guard clause** 模式（一个分支直接 RET，另一个继续执行），不需要 post-dominator——可以通过 "一个后继是 Return 边" 直接识别。

对于完整 if/else（两个分支都继续执行并在 join block 汇合），可以通过 **共同后继检测** 替代 post-dominator：检查 true 分支块和 false 分支块是否有共同后继。本审计的 if/else 检测正是用此方法，识别出 2594 个模式。

### 1.4 Back-edge / Loop Detection — NOT IMPLEMENTED

全仓库搜索 `back_edge|BackEdge|loop_header|LoopHeader` 返回 0 结果。

但通过简单的地址比较（successor address < current block address）可检测到 703 个潜在 back-edge。这证明 loop 在 NtcMach 中大量存在，但 FOX 尚未建立正式的 loop 检测。

### 1.5 x86 Jump Table / Switch — PARTIAL (x64 only)

`recover_msvc_x64_jump_table` 是 x64-only。NtcMach 是 x86，所有 63 个 switch 候选均为 `IndirectJump`（0 targets resolved）。

典型 x86 switch 模式（0x416260）：
```
jnbe 0x4162AF          ; bounds check
jmp [edx*4+0x416318]   ; jump table dispatch
```
当前被识别为 ConditionalJump + IndirectJump，jump table 未解析。

| 0x431830 | 3 | 2 | 待验证 |

### 4.2 Early-Return 典型模式

NtcMach 中 early-return 主要有两种：

**模式 A：Guard Clause（推荐第一目标）**
```
test eax, eax
jz   error_block       ; false 分支 → error / early return
...                    ; true 分支继续正常执行
...
ret                    ; 正常返回
error_block:
...                    ; 错误处理
ret                    ; early return
```

**模式 B：两个分支都 RET**
```
test ecx, ecx
jnz  label_A
xor  eax, eax
ret                    ; 分支 1 返回 0
label_A:
...
ret                    ; 分支 2 返回值
```
（0x401390 即此模式，114 blocks 偏大）

```c

    int result = call_external_2(0x459174, obj);
    if (result == 0) goto error;       // test+jz #2
```

### 7.4 P0-6.4B 最小实现目标

对于 0x41F000，P0-6.4B 只需恢复：

1. **Guard Clause 识别：** `test eax,eax + jz error_block` → `if (eax == 0) goto error`
2. **Early-Return 标注：** error block 以 RET 结尾 → 标记为 early-return path
3. **条件表达式：** 复用 P0-6.3A ConditionRecovery → `eax == 0`
4. **结构化输出（内部表示即可）：** IfElse { condition, true_block, false_block, is_early_return }

**不需要：** Post-Dominator、完整 if/else join 检测、loop、switch、variable recovery、AST、C emitter。
