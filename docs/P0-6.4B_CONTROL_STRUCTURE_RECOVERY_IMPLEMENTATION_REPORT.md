## 1. Architecture

### 1.1 数据模型

新增 `fox-decompiler/src/control_structure.rs`：

```
ControlStructure
├── IfElse
│   ├── condition: ConditionRecovery    (来自 P0-6.3A)
│   ├── branch_block: usize
│   ├── then_block: usize               (ConditionalTrue / taken)
│   ├── else_block: usize               (ConditionalFalse / fallthrough)
│   ├── merge_block: Option<usize>
│   └── evidence: StructureEvidence
├── GuardClause
│   ├── condition: ConditionRecovery
│   ├── branch_block: usize
│   ├── body_block: usize               (normal continuation)
│   ├── return_block: usize             (early-return path)
│   ├── return_is_taken_branch: bool
│   └── evidence: StructureEvidence
└── Unknown
    ├── branch_block: usize
    ├── reason: String
    ├── condition: ConditionRecovery
    └── evidence: StructureEvidence
```

`StructureEvidence` 追溯链：
```
branch_address → true_target_address → false_target_address
→ merge_address (IfElse) → return_edge_detected (GuardClause)
→ detection_reason
```

### 1.2 核心原则

- **CFG 是 Ground Truth**：ControlStructure 是 CFG 之上的语义解释层，不修改 CFG。
- **Condition 唯一来源**：全部复用 P0-6.3A `recover_condition()`，不实现第二套 opcode 逻辑。
- **Fail-Closed**：任何检测条件不满足 → `Unknown`，不猜测。
- **无 Post-Dominator**：使用共同后继检测 + 最短返回路径距离比较。

## 2. Detection

### 2.1 If/Else 判定

```
对于条件分支块 B（有 ConditionalTrue + ConditionalFalse）：
  T = true target block
  F = false target block
  
  如果 T 和 F 存在共同后继 M：
    → IfElse { then=T, else=F, merge=Some(M) }
```

**证据**：共同后继块地址 + 两个分支的 CFG 边。

### 2.2 Guard Clause / Early Return 判定

```
如果没有共同后继：
  d_true  = BFS 最短距离从 T 到含 Return 边的块
  d_false = BFS 最短距离从 F 到含 Return 边的块
  MAX_DEPTH = 15
  
  如果 d_true < d_false：
    → GuardClause { body=F, return=T, return_is_taken=true }
  如果 d_false < d_true：
    → GuardClause { body=T, return=F, return_is_taken=false }
  如果 d_true == d_false（都能返回）：
    → GuardClause { body=false_target, return=true_target, return_is_taken=true }
    （约定：jcc error_block 模式中 taken 分支为 early-return）
  如果只有一个能返回：
    → 该路径为 return，另一路径为 body
```

**Tiebreaker 说明**：当两个分支返回距离相等时（如 0x41F000 第二个 jz，两个分支都直接 ret），采用 `jcc error_block` 约定：taken (ConditionalTrue) 分支为 early-return 路径。这不是语义猜测，而是结构标注约定——该结构确实是一个双返回路径的 if/else，标注哪一侧为 "return" 不影响结构正确性。

### 2.3 Fail-Closed 情况

以下情况 → `Unknown`：
- 分支目标未解析（IndirectJump，target_block=None）
- 无共同后继且无法检测返回路径（两个分支都不在 MAX_DEPTH 内到达 Return）
- SSA 中找不到 CondJump 指令

## 3. Evidence

每个 ControlStructure 携带 `StructureEvidence`：

| 字段 | 来源 |
|---|---|
| branch_address | SSA CondJump 指令地址 |
| true_target_address | CFG ConditionalTrue 边 target_address |
| false_target_address | CFG ConditionalFalse 边 target_address |
| merge_address | CFG 共同后继块 start_address (IfElse only) |
| return_edge_detected | BFS 检测到 Return 边 (GuardClause only) |
| detection_reason | 人类可读的判定依据 |

Condition 来自 `recover_condition(ssa, block_id, inst_idx)`，包含：
- operator (JumpCondition)
- left / right operands
- flags_producer_address
- branch_address
- is_test

**完整追溯链**：
```
ControlStructure
  ↓ StructureEvidence.branch_address
  ↓ SSA CondJump instruction
  ↓ ConditionRecovery (P0-6.3A)
  ↓ FLAGS use-def chain
  ↓ CMP/TEST producer
  ↓ CFG ConditionalTrue/False edges
  ↓ merge/return block
```

## 4. Dogfood: NtcMach 0x41F000

### 4.1 函数概况

- 地址: 0x41F000
- CFG blocks: 4
- SSA blocks: 4
- 2 个 test+jz guard clause（都跳到同一 error block 0x41F02D）
- 2 个 external calls (`call [IAT]`)
- 1 个 indirect call (`call eax`)
- normal return + error/early-return path

### 4.2 恢复结果

```
GUARD_CLAUSE @ 0x41F010: body=block[1] return=block[3] (taken branch)
  condition: (eax.v0 & eax.v0) == 0
  (producer TEST @ 0x41F00E, JZ @ 0x41F010)

GUARD_CLAUSE @ 0x41F020: body=block[2] return=block[3] (taken branch)
  condition: (eax.v0 & eax.v0) == 0
  (producer TEST @ 0x41F01E, JZ @ 0x41F020)

If/Else: 0
GuardClause: 2
Unknown: 0
```

### 4.3 期望的 C-like 语义

```c
void* func_41F000(void* arg) {
    void* obj = external_call_1(0x459188);
    if (obj == NULL) goto error;           // GuardClause @ 0x41F010

    int result = external_call_2(0x459174, obj);
    if (result == 0) goto error;           // GuardClause @ 0x41F020

    return callback(arg);                   // indirect call + normal ret

error:
    // error handling (struct field copy)
    return error_code;
}
```

## 7. Known GAP

1. **Tiebreaker 约定**：双返回路径等距时，默认 taken 分支为 early-return。这是结构标注约定，不影响结构正确性，但未来可通过更精确的 block 复杂度分析改进。
2. **无 Post-Dominator**：复杂 if/else（嵌套、多 join）可能无法通过简单共同后继检测识别。需要 P0-6.5 Post-Dominator。
3. **IfElse 中 condition 的 then/else 语义**：then = ConditionalTrue (taken)，else = ConditionalFalse (fallthrough)。对于 `jz`，then = "if equal"，语义正确。
4. **Unknown 分类较粗**：当前所有 fail-closed 情况都归为 Unknown，未来可细分（indirect_jump / loop / complex_merge 等）。
