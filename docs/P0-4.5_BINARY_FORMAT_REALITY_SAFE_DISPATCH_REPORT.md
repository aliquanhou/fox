# P0-4.5 Binary Format Reality & Safe Dispatch — Implementation Report

**Date**: 2026-09-09
**Phase**: P0-4.5
**Trigger**: Dogfood #1 — DevExpress.BonusSkins.v17.2.dll (.NET CLR assembly caused hang)

## 1. Implementation Summary

P0-4.5 建立 FOX 的 Binary Reality Gate：在进入 Native Analysis Pipeline 之前，首先识别二进制的 Container Format、Execution Model 和 Architecture，对不支持的执行模型 Fail-Closed。

核心成果：
- 新增 `ExecutionModel` 枚举（Native / ManagedCLR / MixedMode / Unknown）
- PE Parser 读取 Data Directory[14] (CLR/COM Descriptor)
- `Binary` 结构体新增 `execution_model`、`clr_present`、`reality_evidence`
- `analyze_binary()` 改为 Safe Dispatch，返回 `FoxResult<AnalysisResult>`
- 新增 `FoxError::UnsupportedExecutionModel`
- CLI `info` 输出执行模型与 Reality Evidence
- CLI `analyze` / `functions` 对 ManagedCLR 快速返回错误
- CLI `disasm` 对 ManagedCLR 拒绝

## 2. Architecture Before

```
Binary
  ↓
PE Parser (reads DD[0] Export, DD[1] Import, DD[5] Reloc)
  ↓
Binary { format, architecture }  ← 无 execution_model
  ↓
analyze_binary(binary) → AnalysisResult  ← 无 Reality Gate，直接 Function Discovery
  ↓
Function Discovery scans ALL of .text as native code
  ↓
.NET DLL → 11MB IL/PNG scanned as x86 → HANG (>45s, must kill)
```

## 3. Architecture After

```
Binary
  ↓
PE Parser (reads DD[0], DD[1], DD[5], DD[14] CLR)
  ↓
Binary { format, architecture, execution_model, clr_present, reality_evidence }
  ↓
analyze_binary(binary) → FoxResult<AnalysisResult>
  ↓
Safe Dispatch:
  ├── Native → Native Pipeline (Function Discovery → CFG → SSA → ...)
  ├── ManagedCLR → Err(UnsupportedExecutionModel) ← 143ms return
  ├── MixedMode → Err(UnsupportedExecutionModel)
  └── Unknown → Err(UnsupportedExecutionModel)
```

pub enum ExecutionModel {

## 5. CLR Detection

**位置**: `crates/fox-binary/src/pe/mod.rs:83-86`

```rust
// Data Directory index 14 = IMAGE_DIRECTORY_ENTRY_COM_DESCRIPTOR
let clr_dd_rva = read_u32(data, dd_offset + 112)?;  // 14 * 8 = 112
let clr_dd_size = read_u32(data, dd_offset + 116)?;
let clr_present = clr_dd_rva != 0 && clr_dd_size != 0;
```

Canonical 判定来自 PE CLR/COM Descriptor，**不依赖 import 中的 mscoree.dll**（import 仅作辅助证据，不作为唯一判定依据）。

## 6. Safe Dispatch

**位置**: `crates/fox-analysis/src/lib.rs:1123-1141`

```rust
pub fn analyze_binary(binary: &Binary) -> FoxResult<AnalysisResult> {
    if !binary.execution_model.native_pipeline_applicable() {
        return Err(FoxError::UnsupportedExecutionModel(format!(
            "Container: {:?}, Architecture: {}, Execution Model: {}, CLR: {}, Native Pipeline: NOT DISPATCHED",
            binary.format, binary.architecture,
            binary.execution_model.display_name(), binary.clr_present,
        )));
    }
    Ok(analyze_binary_native(binary))
}
```

**Breaking change**: 返回类型从 `AnalysisResult` 改为 `FoxResult<AnalysisResult>`。所有调用方（CLI 11处 + 测试 5文件）已更新。

## 8. Reality Evidence

每个 Binary 携带 `reality_evidence: Vec<String>`，记录执行模型分类的因果链：

对于 ManagedCLR：
1. `PE Machine=0x014C (x86 (32-bit))`
2. `CLR/COM Descriptor present: DataDirectory[14] RVA=0x2008, Size=72`
3. `Classification: ManagedCLR (CLR header is canonical indicator)`

对于 Native：
1. `PE Machine=0x8664 (x86-64 (64-bit))`
2. `CLR/COM Descriptor absent: DataDirectory[14] is zero`
3. `Classification: Native (no CLR header)`
