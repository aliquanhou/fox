## 2. 实现方法

### 2.1 两层映射

1. **精确版本映射** (`reg_to_global`): `ecx_7 -> global_46E920`
   - 用于 Expression::Load 路径（有 SSA version）
2. **名称级映射** (`reg_name_to_global`): `ecx -> global_46E920`
   - 用于 Unknown memory operand 路径（只有裸寄存器名）
   - 当寄存器被重新赋值为非 global 值时，此映射被删除

### 2.2 SSA 版本安全

- 当 `ecx_7 = global_46E920` 时，记录 `ecx_7 -> global_46E920` 和 `ecx -> global_46E920`
- 当 `ecx_9 = something_else` 时，删除 `ecx_9` 和 `ecx` 的映射
- 后续 `[ecx+0x20]` 不会传播（因为 `ecx` 映射已被删除）
- **Fail-closed**: 宁可少传播，不允许错误对象归属

### 2.3 两条传播路径

1. **Expression::Load**: `Binary(Add, Variable("ecx", 7), Constant(0x20))` → 查 `ecx_7` → `global_46E920->field_0x20`
2. **Unknown reason**: `memory operand: [ecx+0x20]` → 查 `ecx` → `global_46E920->field_0x20`

## 6. 已知 GAP

### GAP-P0-8.3-CROSS-BLOCK（P1）
当前传播只在顺序遍历 Statement 时生效。如果寄存器在一个基本块中被赋值为 global，然后在另一个基本块中使用，传播可能不生效（因为 emitter 按 Statement 顺序遍历，跨块时映射可能不正确）。

### GAP-P0-8.3-MULTI-REGISTER（P2）
当前只追踪单寄存器赋值。如果 `mov edx, ecx`（ecx 持有 global），edx 不会被追踪为 global。需要简单的寄存器到寄存器传播。

### GAP-P0-8.3-COMPLEX-ADDR（P2）
多级间接寻址 `[eax+ebx*4+0x10]` 无法解析为简单 base+offset，不传播。
